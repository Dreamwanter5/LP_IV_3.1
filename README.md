# LP_IV_3.1

## 📚 Sobre o Projeto

Repositório contendo os exercícios de linguagem de programação desenvolvidos no primeiro semestre de meu terceiro ano do ensino médio técnico integrado em informática, iniciando o uso de PHP para programação.

## 🎯 Objetivo

Este repositório tem como objetivo documentar e compartilhar o aprendizado em PHP, linguagem de programação amplamente utilizada no desenvolvimento web. Os exercícios aqui presentes foram desenvolvidos como parte do currículo escolar, focando em conceitos fundamentais de programação.

## 🛠️ Tecnologias

- **PHP** - Linguagem de programação principal utilizada nos exercícios

## 📖 Conteúdo

Este repositório contém exercícios práticos que abordam conceitos fundamentais de programação em PHP, desenvolvidos durante o primeiro semestre letivo.

## 🚀 Como Usar

Para executar os exercícios deste repositório, você precisará:

1. **PHP** instalado em seu sistema
   - Você pode baixar o PHP em: [php.net](https://www.php.net/downloads)
   
2. Clone o repositório:
   ```bash
   git clone https://github.com/Dreamwanter5/LP_IV_3.1.git
   cd LP_IV_3.1
   ```

3. Execute os arquivos PHP:
   ```bash
   php nome_do_arquivo.php
   ```
